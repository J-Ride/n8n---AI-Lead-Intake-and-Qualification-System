## Project Description

A fully automated lead qualification system built in n8n that receives inbound leads via webhook, scores them using an AI model, and routes each lead through one of three dedicated paths based on score, without any manual involvement.

When a lead submits their project details, the system sends their information to Groq's LLM API which evaluates the lead against explicit business rules and returns a score (HOT, WARM, or COLD), a reason for the score, a personalised email response written specifically to their project type, budget, and timeline, and an internal summary for the sales team.

A Switch node routes execution into one of three named branches based on the AI score. Every branch runs the same three-action chain -- email, Asana, Slack -- with content and urgency calibrated to the lead quality:

- **HOT leads** receive a high-urgency personalised email, an Asana task created directly into the Hot Leads board section, and a fire-emoji Slack alert signalling the team to act immediately
- **WARM leads** receive a personalised email, an Asana task in the Warm Leads section, and a standard Slack notification for follow-up scheduling
- **COLD leads** receive a personalised email, an Asana task logged in the Cold Leads section for record-keeping, and a low-urgency Slack notification

A email copy is generated by the AI and is specific to the individual lead -- no static templates. Every lead regardless of score is captured in Asana, giving the business a complete pipeline record without anyone maintaining a spreadsheet manually.

## Workflow Architecture

'''

Webhook Trigger
    └── Groq AI Lead Scoring (HTTP Request)
            └── Parse AI Response (JavaScript Code Node)
                    └── Switch Node (Routes by AI score: HOT / WARM / COLD)
                            ├── HOT  → Send HOT Email → Create Asana Task (Hot Leads section)  → Send Slack HOT Alert
                            ├── WARM → Send WARM Email → Create Asana Task (Warm Leads section) → Send Slack WARM Alert
                            └── COLD → Send COLD Email → Create Asana Task (Cold Leads section) → Send Slack COLD Alert
'''

## Groq System Prompt

```
You are a lead qualification assistant for LUX Quality Homes, a premium custom home builder
in Kelowna BC. Return a structured JSON response only, no other text.

SCORING RULES - follow these exactly:
HOT = budget $700k+ AND timeline within 12 months AND message shows clear intent
(financing, signed lot, competitor comparison, ready to sign).
WARM = budget $500k-$699k OR timeline 12-24 months OR message shows interest but no urgency.
COLD = budget under $500k OR timeline beyond 24 months OR vague inquiry.

Return exactly this JSON:
{
  "score": "HOT" or "WARM" or "COLD",
  "reason": "one sentence referencing the specific rule that applied",
  "personalized_email_body": "Paragraph 1: acknowledge their specific project type, budget,
  and timeline. No generic openers.\n\nParagraph 2: establish LUX credibility - high-end
  custom homes in the Okanagan, white-glove communication, systems-driven process.\n\n
  Paragraph 3: invite them to a 30 minute discovery call at [CALENDLY_LINK].\n\n
  Warm regards,\nBrad\nFounder, LUX Quality Homes",
  "summary": "2 sentence internal summary for the sales team"
}
```

## Asana Integration Detail

All three lead paths create an Asana task automatically. Each task is routed into
the correct board section at creation time using the `memberships` field in the
API request body, no secondary API call or manual sorting required.

| Lead Score | Asana Section |
|---|---|
| HOT | Hot Leads |
| WARM | Warm Leads |
| COLD | Cold Leads |

Each task includes the lead's full contact details, AI-generated summary, score
reason, and original message in the task notes, giving the sales team full context
without opening a second tool.

'''json
{
  "data": {
    "name": "HOT LEAD: [Client Name] - [Project Type]",
    "notes": "Lead summary, score reason, contact details, and original message",
    "projects": ["YOUR_PROJECT_GID"],
    "memberships": [
      {
        "project": "YOUR_PROJECT_GID",
        "section": "YOUR_SECTION_GID"
      }
    ]
  }
}

## Setup Instructions

1. Import `lead-intake-workflow.json` into your n8n instance via the three-dot menu
2. Connect credentials for Gmail (OAuth2), Asana (HTTP Header Auth), and Slack (Webhook URL)
3. Replace placeholder values:
   - `YOUR_GROQ_API_KEY` in the Groq HTTP node Authorization header
   - `YOUR_ASANA_PROJECT_GID` in both Asana node bodies
   - `YOUR_HOT_SECTION_GID` and `YOUR_WARM_SECTION_GID` in the respective Asana nodes
   - `YOUR_SLACK_WEBHOOK_URL` in both Slack node URL fields
4. Activate the webhook and test using the payload below

## Key Technical Decisions

**Why Groq instead of OpenAI:** Groq's free tier provides access to llama-3.3-70b-versatile
with fast inference. For portfolio and proof-of-concept builds this eliminates cost while
maintaining output quality comparable to GPT-4o on structured tasks.

**Why explicit scoring rules instead of vague criteria:** Leaving the scoring to model
judgment produces inconsistent results across runs. Encoding hard thresholds (budget
dollar amounts, timeline windows, intent signals) makes the scoring deterministic and
auditable -- a requirement for any real business deployment.

**Why a Switch node instead of nested IF nodes:** A Switch node with three named
output routes (HOT, WARM, COLD) produces a cleaner canvas and makes the routing
logic immediately readable to anyone reviewing the workflow. Each branch is visually
distinct and labelled, which matters both for maintainability and for demonstrating
clear system design thinking. Nested IF nodes achieve the same result but produce
a harder-to-read canvas as paths grow.

**Why COLD leads still get an Asana task:** Low-quality leads still represent real
people who made contact. Logging them in the Cold Leads section costs nothing and
gives the business a record of every inquiry without cluttering the active pipeline.
The Slack alert for COLD leads uses a lower-urgency format so the team is informed
but not interrupted.
